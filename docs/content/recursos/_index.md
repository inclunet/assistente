# Recursos

Funcionalidades avançadas do Assistente.

| Recurso | Descrição |
|---|---|
| [Workspaces](WORKSPACES/) | Organize projetos em espaços de trabalho separados |
| [Editor](EDITOR/) | Editor de texto integrado com múltiplas abas e chat inline |
| [Terminal](TERMINAL/) | Terminal integrado com sessões persistentes |
| [Listas de Tarefas](TASK_LISTS/) | Gerencie tarefas com workflows e kanban |
| [Deep Links](DEEP_LINKS/) | Navegação programática via URIs `assistente://` |
| [Hotkeys Globais](HOTKEYS/) | Atalhos de teclado que funcionam mesmo fora do app |
